## About Me

Cybersecurity enthusiast with a strong foundation in **C, C++ and Data Structures & Algorithms**, along with hands-on experience in **ethical hacking, penetration testing, vulnerability assessment, and security research**.

Certified **CWSE** and **CAPT**, with a growing focus on **web application security, vulnerability research, exploit analysis, secure coding, network security, and Linux security**.

I enjoy building practical projects that combine **software engineering, cybersecurity, and systems programming**, while continuously improving my knowledge of **operating systems, computer networks, system architecture, and problem solving**.
